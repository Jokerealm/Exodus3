# Exodus 3 Windows 存档修改器 v1.2

双击 `Exodus3BankEditor.exe` 即可运行，不需要安装 Python，不需要联网。

## 使用

1. 点击右上角“账号 / 存档”，选择本机的 Exodus 3 存档；也可以把 `EX3Data.SC2Bank` 拖到窗口中。
2. 在“常规编辑”中编辑12种资源。“货币 / 样本”同一组集中显示公司勋章、信用点、凭证、神器碎片及三种样本。装备选项仅保留“一键满级”：将已有装备设为20级，威望、改造点数、属性和解锁状态均保留。
3. 在“皮肤 / 外观”中勾选需要的人物皮肤，或点击“解锁全部人物皮肤”；在“穿戴皮肤”中选定外观，也可设置陆战队员静音。选择未解锁的皮肤时会自动补上对应解锁记录。
4. 在“修改预览”里核对本次改变的字段。
5. 点击“导出存档…”保存副本，或在关闭地图后点击“备份并修改”。

“自动暂存草稿”只保存编辑器状态，不会自动写入游戏存档。草稿保存在程序旁的 `data/draft.json`。不需要草稿时点击“清除草稿”。

每次保存都会在目标目录的 `EX3-editor-backups` 文件夹中备份原内容。写回时会检查原文件是否已被游戏或其他程序改变；发现改变会停止写入，要求重新载入。

另存为副本后，游戏实际读取的文件名仍须为 `EX3Data.SC2Bank`。请先退出正在运行的地图，再将所需副本放回对应账号的 Banks/作者ID 目录。保留备份可以恢复原文件。

## 使用提示

修改存档是对作者工作的不敬，仅供体验，请在24小时内放弃修改。

## 修改范围

- 勋章的整数与 Medal-en 配套编码一起生成，并同步 C/C 里的勋章显示副本与 CS/CS 汇总校验。
- 资源修改同步 R/R 密文和 RS/RS 汇总校验，完整保留其他资源项。
- 装备仅提供20级满级操作，并同步 WS/PAS/TS/SS 配套校验与 EC/ECA 汇总；不改动威望、改造点数、属性和解锁状态。旧草稿里的装备解锁和改造点数选项会被忽略。
- “更多字段”可以编辑公司区块 EECompany 的其他整数，并生成配套编码；其他区块供只读浏览和搜索。
- 人物皮肤解锁写入 CUSTOM/SK，穿戴写入 CUSTOM/MM。共42款人物皮肤，其中标准、普通默认免费，另外40款支持单独勾选或全部写入解锁记录。
- 枪皮和头顶、脚下光环还有地图名单检查，SK人物解锁记录不会自动放行它们；编辑器显示原存档值并保留。详见“皮肤解锁说明.md”。
- 其他未修改字段、注释、未知节点及值类型保留。完全不做修改时，导出与输入逐字节相同。
- 有原始 Bank 签名时，使用玩家ID、作者ID和原始存档名更新签名；无签名存档仍保持无签名。
- 勋章支持0–2,706,911；资源支持0–90,000,000；装备批处理支持当前12资源地图版本。

## 验证范围

已通过本地加解密、24个记录勋章样本、全部1737个当前原始数字密文块的往返检查，以及GUI导入、编辑、预览、重置、草稿恢复、备份、导出和过期文件保护测试。现有147个整数配套字段都与源码复现一致。新版另外通过18项专项检查，确认只修改装备等级、保留多种威望值、忽略旧装备选项草稿，以及按钮与提示正常显示。新增皮肤功能通过22项读写与界面检查，并用地图同款解密逻辑确认完整多块解锁名单可读取。独立EXE已成功启动并渲染界面，测试未改动原游戏存档。

程序基于本次提取的 Exodus 3 地图脚本。新生成数值尚未经过本次游戏内验收；地图更新也可能改变存储格式或检测规则。
