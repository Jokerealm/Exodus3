# v1.3 test版新增矿物

常规编辑新增三个矿物输入框，范围均为0–90,000,000。

| R/R中的项（从1开始） | 地图名称 | 脚本名称 |
| --- | --- | --- |
| 13 | 柚矿 | Uranium |
| 14 | 铪矿 | Hafnium |
| 15 | 钼矿 | Molybdenum |

“柚矿”沿用地图本地化文字，脚本的内部名称为Uranium（铀）。

## 使用与兼容

- 12项存档默认不补字段；勾选“编辑 test 新增矿物（柚 / 铪 / 钼）”后启用三项，导出时将R/R补齐到15项。
- 已有15项存档自动读取和启用新矿物，不允许通过取消勾选丢弃现有字段。
- “全部设为…”作用于当前启用的矿物；原来的草稿仍可恢复，新草稿会记住是否启用test矿物。
- 修改资源时保留未改动的密文块与未知尾项，RS/RS及RS-en覆盖实际写出的全部资源之和。
- 旧版12项装备满级功能的支持范围保持不变，15项存档的该选项禁用。

## 地图保存限制

当前test地图的资源写出数量为：

`12 + (16 - 13) * ((2 * (活跃玩家数 - 1)) / 活跃玩家数)`

脚本在这里使用整数除法，1名活跃玩家时写12项，2名及以上写15项。资源汇总校验使用同一上限。因此，即使编辑器补齐了新矿物，单人局保存后仍可能被地图删去，需在多人局验证持久保存。读取时地图支持第1–15项。
