# Exodus 3 人物皮肤解锁说明

本说明对应本次缓存提取的地图脚本，地图包 SHA-256 标识为 `0f5886c009452d1c02031ec6411ea232db8b025f75c386ef149f367c268152f7`。

## 修改器怎么使用

导入 EX3Data.SC2Bank，打开“皮肤 / 外观”。勾选人物皮肤，或点击“解锁全部人物皮肤”，然后选择穿戴外观。核对“修改预览”后导出，或关闭地图后备份并修改。更改在导出或写回之前都只是编辑器中的草稿。

共42款人物皮肤。索引0“标准”和28“普通”默认免费，另外40款可写入存档解锁名单。选择尚未解锁的外观时，修改器会同时写入解锁记录和穿戴值。勾选框只显示存档授权，不包含玩家可能已有的地图购买名单权限。重新进入地图后，可用 F8 打开皮肤面板查看。

## 存档与检查逻辑

| 字段 | 内容 | 本版编辑器 |
| --- | --- | --- |
| CUSTOM/SK | 用逗号分隔的皮肤索引名单，整串加密，例如 `5,20,40` | 单独勾选、全部解锁；保留未知未来索引 |
| CUSTOM/MM | 当前人物皮肤索引，加密整数 | 穿戴选择；自动补上对应SK授权 |
| CUSTOM/SV | 陆战队员语音静音开关，1静音、0开启 | 可修改 |
| CUSTOM/HH | 头顶光环 | 显示原值、保留 |
| CUSTOM/HF | 脚下光环 | 显示原值、保留 |
| CUSTOM/GG | 枪皮索引 | 显示原值、保留 |

人物皮肤检查函数 `EE_SK_CanUse` 接受SK中的索引授权。只改MM没有补SK时，检查可能将穿戴重置为标准外观。SK必须是整串加密后的逗号名单，不能把多个独立数字密文拼在一起。

头顶光环和脚下光环分别检查地图的皮肤12、13拥有者名单；这两处没有调用SK授权检查。仅勾选“暗影”或“鎏金”不会解锁对应光环。

正式地图的枪皮还要求佣兵系列人物模型（28–41）。机枪是免费枪皮，其他枪皮检查地图的独立拥有者名单。因此本版没有提供会被地图重新拒绝的枪皮或光环解锁开关。
